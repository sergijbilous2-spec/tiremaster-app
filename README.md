# 🚗 TireMaster Pro — Telegram Mini App для шиномонтажу

Вебзастосунок (Telegram Mini App) для онлайн-запису клієнтів на шиномонтаж з інтерактивною 3D-візуалізацією автомобіля, розрахунком вартості послуг, збереженням історії заявок та автоматичними сповіщеннями майстрам у Telegram.

## ✨ Основний функціонал

* **Інтерактивна 3D-сцена (`Three.js`):** візуальне представлення авто та фокусування на обраних послугах.
* **Онлайн-запис та розрахунок вартості:** вибір послуг, типу авто, поста та часу з динамічним підрахунком суми.
* **Історія замовлень і статуси:** збереження заявок у `localStorage` для миттєвого доступу після оновлення сторінки (`F5`) та повторного входу з синхронізацією через бекенд.
* **Скасування записів та сповіщення майстрів:** обробка скасувань через API з миттєвим сповіщенням майстрів у Telegram.
* **Інтеграція з Telegram WebApp:** коректна робота всередині Telegram Mini App і в звичайному браузері для локального тестування.

## 🛠 Стек технологій

* **Frontend:** HTML5, CSS3, Vanilla JavaScript, Three.js, Telegram WebApp API
* **Backend:** Python, FastAPI
* **База даних:** SQLite
* **Сповіщення:** Telegram Bot API
